# 电费计费系统

## 功能列表
1. **阶梯电价计算**：支持三个阶梯的电价计算
2. **峰谷时段调节**：根据用电时段调整费率
3. **系统初始化**：显示计费规则版本号和初始化时间
4. **用户输入**：引导用户输入用电量和用电时段
5. **账单明细**：打印详细的账单信息
6. **单元测试**：针对核心函数编写单元测试

## 实现思路
1. **阶梯计费逻辑**：使用条件判断，根据用电量的不同范围计算不同阶梯的电费
2. **峰谷时段处理**：根据输入的小时数判断是高峰时段还是低谷时段，应用不同的调节因子
3. **模块化设计**：将功能拆分为多个函数，提高代码的可维护性和可读性
4. **常量定义**：使用const定义所有的阶梯阈值和单价，便于后续维护和调整
5. **单元测试**：针对核心函数编写测试用例，确保计算逻辑的正确性

## 函数列表

| 函数名 | 功能说明 |
|-------|--------|
| `init()` | 初始化系统，打印计费规则版本号和系统初始化时间 |
| `calculateTierBill(amount float64) float64` | 计算阶梯电费 |
| `calculateTimeFactor(hour int) float64` | 计算峰谷平调节因子 |
| `calculateTotalBill(amount float64, hour int) float64` | 计算最终电费 |
| `getHourFromTimeString(timeStr string) (int, error)` | 从时间字符串中提取小时 |
| `runBilling()` | 运行计费流程，引导用户输入并打印账单明细 |
| `main()` | 主函数，调用runBilling() |

## 跨阶梯计费的逻辑难点
在处理跨阶梯计费时，需要注意以下逻辑难点：
1. **边界值处理**：确保在阶梯阈值处的计算正确，比如200度和400度时的电费计算
2. **分段计算**：需要将用电量分成不同的阶梯部分，分别计算每部分的电费，然后累加
3. **精度问题**：由于涉及浮点数计算，需要注意精度问题，确保最终结果的准确性
4. **时段判断**：需要正确判断用电时段是高峰还是低谷，应用相应的调节因子
